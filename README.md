# 🐐 GOAT RAMPAGE — 쉬운 실행 & 배포 가이드

## ① 지금 당장 혼자 해보기 (설치 ❌, 3초)

**`public/index.html` 을 더블클릭** (또는 맨 위 `index.html`) → 브라우저에서 바로 실행!

| 되는 것 (파일만으로 OK) | 서버가 있어야 하는 것 |
|---|---|
| 스토리 모드, CPU 대전, 로컬 2P, 월드맵, 프로필, 설정 | 온라인 대전, 회원가입/로그인, 랭킹 |

진행 상황은 그 브라우저에 자동 저장됩니다. 폰/다른 PC로 파일을 옮겨도 열립니다.

---

## ② 인터넷에 올려서 친구랑 하기 — 뭘 고를까?

게임은 **두 부분**입니다.

- 🖼️ **화면(클라이언트)** = `public/index.html` → GitHub / Cloudflare / Firebase 에 **무료**로 올림
- 🖥️ **서버** = 온라인 대전·로그인용 (`server/` 폴더, Node.js) → **Render** 같은 서버 호스팅이 필요

> ⚠️ GitHub Pages / Cloudflare Pages / Firebase Hosting 은 "화면 파일만" 올릴 수 있는 곳이라
> 온라인 대전용 서버는 **못 돌립니다.** 그래서 서버는 Render에 따로 올립니다.

### 🥇 가장 쉬운 길 (추천) — 한 곳에 전부
👉 **[docs/1-서버-Render.md](docs/1-서버-Render.md)** 만 따라 하면 끝.
서버가 게임 화면까지 같이 보여주기 때문에 주소 하나(`https://xxxx.onrender.com`)로 접속하면 온라인 대전까지 됩니다.

### 🖼️ 화면만 따로 올리고 싶다면 (서버는 위 Render 사용)
- 👉 [docs/2-GitHub.md](docs/2-GitHub.md) — 코드 올리기 + GitHub Pages (자동 배포)
- 👉 [docs/3-Cloudflare.md](docs/3-Cloudflare.md) — Cloudflare Pages
- 👉 [docs/4-Firebase.md](docs/4-Firebase.md) — Firebase Hosting

화면을 따로 올렸다면 **`public/index.html` 맨 위의 `GOAT_SERVER_URL`** 한 줄에 Render 주소를 넣어야
온라인 대전이 연결됩니다. (방법은 각 가이드에 있음)

## ③ 내 PC에서 서버까지 켜보기 (선택)
1. [Node.js](https://nodejs.org) (LTS) 설치
2. 이 폴더에서 터미널 열고:
   ```
   npm install
   npm start
   ```
3. 브라우저에서 `http://localhost:3001` 접속 (또는 `public/index.html` 더블클릭해도 자동 연결)

## 폴더 설명
```
index.html          → public/index.html 로 이동시켜 주는 입구
public/index.html   → 게임 본체 (파일 하나에 다 들어있음)
server/ shared/     → 온라인 대전·로그인 서버 소스
render.yaml         → Render 자동 설정
firebase.json       → Firebase Hosting 설정
.github/workflows   → GitHub Pages 자동 배포 설정
```

## 알아둘 점
- Render **무료 플랜**은 보통 한동안 접속이 없으면 서버가 잠들어서, 첫 접속이 30초~1분 느릴 수 있어요.
- 무료 플랜은 서버 재시작/재배포 때 **계정·랭킹 데이터가 초기화**될 수 있어요. (유료 디스크를 붙이면 유지됨 — 가이드 참고)
- 서버에 저장되는 비밀번호는 해시 처리되지만, 정식 서비스 수준의 보안 점검은 안 된 상태입니다.

## 📖 스토리 & 연출 (이번 패치)
**줄거리:** 부서진 〈황금 방울〉의 다섯 조각을 모아 〈붉은 달의 문〉을 닫는 이야기. 챕터 1~5, 보스마다 사연이 있습니다.

| 추가된 것 | 설명 |
|---|---|
| 프롤로그 / 챕터 타이틀 | 처음 스토리에 들어가면 프롤로그, 지역마다 챕터 카드와 도입 대사 |
| NPC 대화 | 초상화 + 타자기 대사. 첫 만남 / 재방문 / 퀘스트 완료 / 보스 격파 후로 대사가 달라짐 |
| 보스 조우 | 보스 전용 대사 → **VS 스플래시** → 전투. 패배하면 보스가 한마디 |
| 보스 격파 | 격파 대사 → 〈조각 획득 n/5〉 연출 → 다음 목적지 안내 |
| 엔딩 | OMEGA RAM 격파 시 엔딩 내레이션 + 장로 버키의 에필로그 + THE END |
| 필드 분위기 | 지역별 파티클(꽃가루·반딧불·재·불씨·금가루), 숲의 번개, 보스 접근 경고, 퀘스트 ❗/✔ 표시, 조각 개수 표시 |

- 컷신은 **화면 탭 / Enter / Space / J** 로 넘기고, 오른쪽 위 **SKIP ▶▶** 으로 건너뜁니다.
- 이미 본 컷신(프롤로그, 챕터 도입, 보스 첫 대사)은 다시 안 나옵니다. 다시 보려면 브라우저 데이터를 지우세요.
- 대사를 고치고 싶다면 `story/story-patch.js` 의 `NPC`, `BOSS`, `CHAPTER`, `PROLOGUE`, `ENDING` 항목을 수정한 뒤, 같은 내용을 `public/index.html` 의 `story-patch` 블록에 붙여 넣으면 됩니다.

## 📖 스토리 확장 (v2)
- **라이벌 대시**: 챕터 1·3에서 결투(실제 전투), 챕터 2에서 구출, 챕터 5에서 합류. 결투 후 손을 내밀지 선택.
- **필드 이벤트**: 각 지역을 걷다 보면 자동 발생 (꼬마 콩이, 고목의 환영, 약속의 호루라기, 베일의 회상, 붉은 달의 속삭임, 버키의 고백).
- **선택지**: 숫자 키(1/2/3) 또는 화면 터치. 선택은 보스의 대사와 **엔딩**에 반영됩니다.
- **반전**: 방울을 부순 사람은 누구인가? (직접 확인해 보세요)
- **엔딩 3종**: 함께 울린 방울(TRUE) / 황금 방울의 챔피언 / 외로운 챔피언
- **📖 일지**: 스토리 화면 왼쪽 위 `📖 일지` 버튼 → 단서·관계 점수·본 엔딩·TRUE END 힌트
- 🗑 초기화에서 "스토리 컷신만 다시 보기"를 누르면 선택 기록도 함께 지워집니다.

## 🐐 염소 울음소리
브라우저에서 직접 합성한 "메에~" 소리입니다 (별도 음원 파일 없음).
- 대사가 시작될 때 말하는 캐릭터마다 다른 높이로 울음 (장로는 낮고 길게, 꼬마는 높게)
- VS 화면, 보스 접근 경고, TRUE 엔딩(합창), 박치기/스페셜 입력 시, 필드에서 가끔 들리는 환경음
- 끄려면 메인 메뉴 🗑 초기화 → **🐐 염소 울음소리 켜기/끄기**

## 🔧 수정: 스토리 모드 캐릭터 교체
스토리 화면 오른쪽 위 `🐐 ○○ 교체` 버튼이 눌러도 항상 첫 캐릭터(RAM)로 돌아가던 문제를 고쳤습니다. 이제 교체한 캐릭터가 유지되고(전투·컷신 초상화에도 반영), 브라우저를 다시 열어도 기억합니다.
