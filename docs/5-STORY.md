# GOAT RAMPAGE — 스토리 설정집 (Story Bible)

## 한 줄 요약
붉은 달의 밤에 부서진 〈황금 방울〉의 다섯 조각을 모아, 방울을 〈붉은 달의 문〉을 닫는 **자물쇠**로 다시 벼리는 이야기.

## 핵심 비밀 (스포일러)
- 방울은 울릴 때마다 문을 조금씩 여는 **열쇠**였다.
- 방울을 부순 사람은 **장로 버키** ("여섯 번째 종지기"). 문을 닫으려던 선택이었지만, 조각이 챔피언들의 마음을 삼켜 광란이 시작됐다.
- OMEGA RAM은 마지막 조각을 품고 문 앞을 홀로 지킨 **버키의 첫 제자**. 보스전은 "문을 대신 닫을 자격"의 시험.

## 등장인물
| 이름 | 역할 |
|---|---|
| 플레이어(방울의 아이) | 버키에게 방울을 받은, 두려움 없이 방울을 울릴 수 있는 아이 |
| 장로 버키 | 수련 교관 / 방울을 부순 사람 |
| 라이벌 대시 | 같은 스승 밑에서 자란 라이벌. 방울에 선택받지 못했다 |
| 베일 / PHANTOM | 그림자 추격자 / 그의 형 (조각에 이름을 잃음) |
| BRUTUS · VOLT · TITAN | 계곡의 경비대장 · 숲을 살리려던 마공학자 · 도시의 성문지기 |
| OMEGA RAM | 그랜드 챔피언, 마지막 조각의 수호자 |
| 붉은 달의 속삭임 | 문 저편의 소리. 보스를 쓰러뜨릴 때마다 한마디씩 등장 |

## 선택과 엔딩
| 기록 | 올리는 법 |
|---|---|
| `bond` (대시와의 유대, 최대 4) | 대시 구출(자동 +1), 구출 후 "같이 가보자", 결투 ①②후 손 내밀기/함께 가자 |
| `kind` (마음씨, 최대 3) | 콩이 돕기, 호루라기 받기, 베일과 약속 |
| `bucky_trust` | 버키의 고백에서 "혼자 짊어질 일이 아니었어요" |
| 단서 | `vision` · `key_clue` · `mural` · `moon_talk` · `confession` |

- **TRUE END 〈함께 울린 방울〉**: bond ≥ 3 · kind ≥ 2 · bucky_trust 1
- **SOLO END 〈외로운 챔피언〉**: bond ≤ 1 이고 bucky_trust 0
- **GOOD END 〈황금 방울의 챔피언〉**: 그 외

선택은 보스 격파 대사(콩이·호루라기·약속·버키 이야기)에도 반영됩니다.

## 연출/시스템 메모
- 컷신 조작: 탭/Enter/Space/J, SKIP(선택지는 건너뛰지 않음), ⏩ 글자 속도, 선택지는 1·2·3 키 또는 터치.
- 퀘스트 안내 줄은 SKIP 해도 항상 표시됩니다.
- 이미 보스를 클리어한 기존 세이브는 해당 지역 컷신을 조용히 건너뜁니다.
- 일지(📖)에서 단서·관계·엔딩 확인과 **엔딩 다시 보기** 가능.
- 클리어한 챔피언이 다른 지역에서 야생으로 나올 때는 "광란의 ○○"(조각의 메아리)로 표기됩니다.
